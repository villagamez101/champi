# 01_context

**Stable rules of the project**: identity, brand voice, style guides, what
"correct" means here. This is the *factory configuration*, not the product.

Examples of what lives here: brand identity, tone of voice, visual rules,
work conventions, quality criteria.

- Changes rarely — when the rules themselves change, not per task.
- The agent loads this as **context** (constraints to follow), unlike
  `02_resources/docs/` which is **knowledge** (consulted on demand).
