# 04_templates

Blueprints for **recurring deliverables**: the fixed skeleton an output must
have (structure, required sections, tokens like `{{name}}`, design constraints).

**Skill vs template:**

| | Skill (`.opencode/skills/`) | Template (here) |
|---|---|---|
| Is | A *procedure*: how the agent should act | A *skeleton*: what the deliverable must contain |
| Scope | Cross-project | Per project/brand |

Create a file here only when a deliverable format repeats **3+ times**. Before
that, graduated examples in `02_resources/docs/` work as improvised templates.
