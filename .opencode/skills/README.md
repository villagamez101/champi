# .opencode/skills

Packaged capabilities the agent loads on demand (they became a cross-tool
standard: `SKILL.md` with `name` + `description`).

- The `description` is the routing signal: the agent reads it and decides
  whether to load the full skill. Write it precisely ("Use when creating
  promotional banners following brand rules").
- folders here are NOT placeholders; create one folder per skill when you
  write one.
- See templates-vs-skills note in `04_templates/README.md`.
